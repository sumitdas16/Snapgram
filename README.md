# Snapgram

Snapgram is a full-stack social media web application that allows users to create, read, update, and delete posts, as well as manage their profiles. The project is built using **TypeScript** and **React** on the frontend and leverages **Appwrite** for backend services such as authentication, database, and storage.

## Features

- User registration and login via email.
- CRUD operations (Create, Read, Update, Delete) for posts.
- User profile management (update user details).
- Secure authentication and data storage using Appwrite.
- Responsive design for an optimal experience across devices.

## Technologies Used

- **Frontend**: TypeScript, React
- **Backend**: Appwrite (Database, Authentication, and Storage)
- **CSS/Styling**: Tailwind CSS (or any other framework if used)
